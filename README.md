### 🚀 About Me

I am a software engineering student at **42 Bangkok**, focused on **systems programming**, **low-level computing**, **concurrency**, and **network architectures**.

* 🔭 **Currently Focusing On**: Modern C++, distributed systems, operating system primitives, and backend infrastructure.
* 🎓 **42 Curriculum**: Completed the rigorous **42 Common Core** (ranks `r00` through `r05`), building UNIX shells, HTTP servers, raytracers, and multi-threaded simulations under strict **Norminette** standards.
* 🧠 **Core Philosophy**: Understanding abstractions from first principles by implementing libc, memory allocators, pipelines, and networking engines from scratch.
* 💬 **Ask Me About**: C, C++, POSIX threads, UNIX signals & sockets, Docker, and algorithmic complexity.
